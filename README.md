# Подбор запчастей

Клиентское приложение на React и JavaScript с Redux Toolkit / RTK Query, Bootstrap и SCSS.

## Сценарий работы

1. Введите артикул и нажмите «Найти» или Enter. Таблица сразу показывает детали разных производителей с этим артикулом, их склады, цены и остатки.
2. Для получения аналогов откройте «Фильтры», выберите производителя детали и нажмите «Применить».
3. Выбор производителя находится только в панели фильтров. «Все производители» возвращает к первому ответу по артикулу без нового запроса.
4. В той же панели доступны локальные условия по складу, наличию и типу позиции.
5. Внизу слева кнопками выберите 10, 50 или 100 строк на странице.
6. Значок в колонке цены переключает три состояния: исходный порядок, цена по возрастанию, цена по убыванию.

Сортировка и пагинация также выполняются на клиенте, по полной загруженной выдаче. API поставщика не предоставляет параметры страниц в используемом контракте.

## Запуск

Нужен Node.js 22.12+ или 24 и npm.

Скопируйте `.env.example` в `.env.local` и заполните `FAVORIT_API_KEY` и `FAVORIT_API_URL`. В шаблоне значения заполнены только для локальных адресов.

```bash
npm install
npm run dev
```

## Проверки и запуск сборки

```bash
npm test
npm run build
npm start
```

`npm start` раздаёт `dist/` и обслуживает API без Vite. По умолчанию адрес — `http://127.0.0.1:3000`; `HOST` и `PORT` можно изменить в серверном окружении.

Тесты используют контролируемые ответы и не обращаются к поставщику.


P.S.
Поиск запускается по нажатию или Enter вместо автоматического запроса при вводе, а производитель выбирается внутри фильтров вместо отдельного шага
Эти решения были приняты в пользу компактности интерфейса и экономии запросов исходя из "у нас для
каждого клиента есть ограничения на поиск грузовых запчастей"
